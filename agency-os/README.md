# Whisker & Heat Agency OS

A copy of SignalIQ's Agency OS (`~/Desktop/agency-os`), running beside it on LOKI with its own data. Nothing here reads or writes Signal's posts, workflows or accounts.

| Part | Where on LOKI | Port |
|---|---|---|
| Data | database `whiskerheat`, schema `agencyos` (same structure as Signal's), tenant `whisker` | Postgres |
| API | `/opt/whisker-os-api` (Signal's API, pointed at `whiskerheat`), systemd `whisker-os-api` | 3057 |
| Slide renderer | `/opt/whisker-os-render` ← `render/render.ts` (adds food-photo and character slides), systemd `whisker-os-render` | 3058 |
| Dashboard | `/opt/whisker-os-dashboard` ← `dashboard/` (rebranded), systemd `whisker-os-dashboard`, public at https://whiskerflame.safetykat.com/agency-os/ | 3056 |
| Workflows | n8n on LOKI, ids `wos-wf0`…`wos-wf5`, generated by `scripts/build_workflows.py` | — |
| Settings | `/opt/n8n/whisker-os-api.env`, `whisker-os-render.env`, `whisker-os-dashboard.env`, `whisker-os.env` (n8n). Never in this repository |

Sign-in is the same emailed one-time link as Signal's, to the owner email.

## Workflows

WF0 error handler (on), WF1 weekly planner (Sunday 17:00; off until the OpenAI account has credits), WF2 slide render (every 5 min, on), WF3a approval digest (off), WF4 publisher (off until Whisker's Instagram is connected), WF5 insights (off). Signal's WhatsApp approval commands (WF3b) and Meta setup check (WF9) are not copied: they answer the shared Magnovent number.

Edit `scripts/build_workflows.py`, run it, import the JSON with `n8n import:workflow`, then `n8n update:workflow --id=<id> --active=true` and restart n8n.

## Loading a week by hand

`scripts/load-week.mjs` loads a planned week (for example `content/week-2026-10-19.json`) through the API exactly as WF1 does.
